# ShabdAnveshi frontend

React, TypeScript and Vite implementation of the approved Quiet Conversation design.

## Run

With Node.js 22.12+ and npm installed:

```powershell
cd "D:\sem 5\ShabdAnveshi\frontend"
npm ci
npm run dev
```

The first visit opens a language dialog. English and Hindi interface preferences are saved locally. Search result language is a separate preference, with an option for both languages. The About page includes the project journey, implemented search logic, toolkit, student details and real LinkedIn/repository links.

## Search service

Run the Python service using [backend instructions](../backend/README.md). Without `VITE_API_URL`, submitting a description explains that the search service is not connected. **Explore a sample conversation** shows explicitly labeled illustrative results; those results are not generated by a model.

Copy `.env.example` to `.env.local` and set the backend URL. Restart Vite after changing this value. The API must allow the frontend's origin through CORS. `VITE_` values are public configuration, not secrets.

Expected request:

```http
POST /api/predict
Content-Type: application/json
```

```json
{
  "description": "someone who loves books",
  "language": "en",
  "starting_letter": null,
  "approximate_length": null,
  "part_of_speech": null,
  "limit": 5
}
```

`language` supports `en`, `hi`, and `both`. A non-null part of speech is `noun`, `verb`, `adjective`, or `adverb`. Approximate length must be interpreted consistently with the Hindi corpus; Unicode code units should not be assumed to represent visible characters.

Expected response shape (illustrative):

```json
{
  "suggestions": [
    {
      "word": "Bibliophile",
      "definition": "A person who loves or collects books.",
      "language": "en",
      "part_of_speech": "noun"
    }
  ]
}
```

An optional numeric `score` is a similarity measure, not a confidence probability. Real results also include `source`, `source_url` and `definition_language`. Source links are restricted to HTTPS; Hindi entries with English definitions are explicitly labeled. Invalid responses and network failures leave the typed description available for retry. Requests time out after 180 seconds to accommodate slower free-tier inference. Busy (429), unavailable (503) and invalid clue (422) responses have separate messages.

## Production build

```powershell
npm run build
npm run preview
```

For the GitHub Pages project path, build with:

```powershell
npm run build -- --base=/shabdanveshi/
```

Hash routes (`#about`, `#settings`) avoid server-side routing requirements. Deployment configuration is a later stage. Google Fonts are optional external style resources; system fonts provide fallbacks.
